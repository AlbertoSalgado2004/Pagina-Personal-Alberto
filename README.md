# Mi página personal

Este proyecto corresponde a una practico de **Diseño de Sistemas en Internet**. Consiste en crear una página personal sencilla utilizando la estructura básica de HTML.

## ¿Qué contiene la página?

- Un encabezado con mi nombre.
- Un párrafo de presentación personal.
- Una imagen personal.
- Una lista de intereses.
- Enlaces a sitios web favoritos.

## Archivos del proyecto

- `index.html`: contiene la estructura y el contenido de la página, junto con estilos básicos.
- `IMG-20251223-WA0039.jpg`: imagen ilustrativa que aparece en la página.
- `README.md`: descripción del proyecto.

## Cómo visualizar la página

1. Descargar los archivos del repositorio.
2. Mantener `index.html` e `IMG-20251223-WA0039.jpg` en la misma carpeta.
3. Abrir `index.html` en un navegador web.

## Tecnologías utilizadas

- **HTML5** para organizar el contenido de la página.
- **CSS** para aplicar un diseño sencillo.
